# Mãos do Vale

Projeto acadêmico de desenvolvimento front-end desenvolvido para representar uma organização do terceiro setor.

## Sobre o projeto

A Mãos do Vale é uma aplicação web criada para apresentar iniciativas sociais, voluntariado e informações institucionais de uma organização do terceiro setor.

O projeto foi desenvolvido utilizando HTML5, CSS3 e JavaScript nativo, com foco em organização estrutural, responsividade, acessibilidade, interatividade e persistência local de dados.

## Funcionalidades

- Navegação dinâmica por meio de uma Single Page Application (SPA);
- Templates dinâmicos utilizando JavaScript;
- Menu responsivo com menu hambúrguer;
- Dropdown para navegação dos projetos;
- Formulário de cadastro de voluntários;
- Validação nativa dos campos;
- Máscaras para CPF, telefone e CEP;
- Validação dos dígitos verificadores do CPF;
- Persistência dos dados do formulário utilizando localStorage;
- Componentes de feedback, como toast, alerta e modal;
- Layout responsivo utilizando CSS Grid e Flexbox;
- Recursos de acessibilidade com HTML semântico e atributos WAI-ARIA.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- CSS Grid
- Flexbox
- DOM API
- History API
- localStorage
- Git
- GitHub
- GitHub Actions
- GitHub Pages
